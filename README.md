# Customer Segmentation Analysis

## Project Overview
This project focuses on analyzing customer transaction data to understand purchasing behavior, spending patterns, and revenue distribution. The analysis helps identify distinct customer segments based on their purchasing activities.

## Objectives
- Understand customer purchasing behavior.
- Analyze spending patterns and revenue distribution.
- Identify meaningful customer segments.
- Present key findings through interactive visualizations.

## Tools & Technologies
- Python
- Pandas
- Power BI

## Project Workflow
1. Data loading and initial exploration.
2. Data cleaning and preprocessing using Python and Pandas.
3. Exploratory Data Analysis (EDA) to identify customer and revenue patterns.
4. Customer segmentation based on purchasing behavior.
5. Dashboard creation in Power BI to present insights.

## Dashboard
The Power BI dashboard provides a visual overview of customer segments, purchasing patterns, and revenue insights.
